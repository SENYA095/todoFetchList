# Todo App (Next.js + JSONPlaceholder)

A simple Todo app built with **Next.js App Router**, **Tailwind CSS**, and the **JSONPlaceholder API**.

## 🚀 Features
- Fetch todos from JSONPlaceholder API (`_limit=10`)
- Add new todos (stored locally)
- Delete todos
- Responsive & styled with TailwindCSS

## 🛠️ Tech Stack
- Next.js (App Router)
- TypeScript
- React Hooks (`useState`, `useEffect`)
- Axios for HTTP requests
- Tailwind CSS for styling
